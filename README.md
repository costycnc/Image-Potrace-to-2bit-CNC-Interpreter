# Image Potrace to 2-Bit CNC Interpreter

This educational, open-source project demonstrates how to drive a CNC machine (like the CostyCNC) directly from vectorized bitmap paths using the **Potrace** algorithm, completely bypassing traditional, heavy G-code text (`G01 X.. Y..`).

The entire architecture is designed with a strict **minimalist, bare-metal** philosophy. It is ideal for teaching hardware-software interfacing, bitwise logic optimization, and low-level microcontroller programming.

---

## 💡 The Educational Concept

In industrial CNC systems, sending ASCII strings like `G01 X1000` forces the microcontroller to waste memory parsing strings and utilize heavy CPU cycles calculating paths. 

This project shifts all computational overhead to the PC software (JavaScript). The hardware receives a **stream of pre-calculated bits** and acts as a pure, ultra-fast signal execution engine.

```text
[ Bitmap Image ]
       │
       ▼ (Potrace Algorithm)
[ Separated Paths ]
       │
       ▼ (JavaScript: extract function)
[ Optimized Continuous Path ]
       │
       ▼ (Bitwise JS Encoder)
[ 2-Bit Compressed Byte Stream ]
       │
       ▼ (Serial Communication)
[ AVR Assembly Interpreter (MCU) ] ──> [ Physical Motor Pulses ]
```

---

## 🔩 Minimalist 2-Bit Motion Encoding

Instead of transmitting absolute coordinates or verbose text, every single step of the stepper motors is encoded using just **2 bits** (allowing for 4 possible directions):

* **`00`** = Move **Right** (+X)
* **`01`** = Move **Left** (-X)
* **`10`** = Move **Up** (+Y)
* **`11`** = Move **Down** (-Y)

Since 1 Byte consists of 8 bits, we successfully pack **4 full sequential CNC step movements into a single transmitted Byte**!

### Step Example: A 1-pixel Square
Movement path: Right → Up → Left → Down.
* Bit sequence: `00` `10` `01` `11`
* Final generated Byte: `00100111` (Decimal value: `39`)

## 📂 Repository Structure

The project is stripped to its bare essentials for student accessibility:

1. **`generator.js`**: Takes the vector paths from Potrace, runs CostyCNC's `extract()` algorithm to merge paths and minimize travel time, and converts the resulting coordinates into the 2-bit binary stream.
2. **`interpreter.asm`**: Pure AVR Assembly machine code for the ATmega328P. It reads bytes from the hardware serial buffer, isolates the 2-bit commands via logical masks (`ANDI`) and bit shifts (`LSL`), and directly triggers the physical STEP and DIR motor driver pins.

---

## 🚀 Key Advantages

* **Zero Math Overhead on the MCU**: The microcontroller runs zero interpolation math or acceleration ramps.
* **Bandwidth Optimization**: The binary data stream is incredibly light, making it ideal for low-speed wireless links or low-frequency legacy chips.
* **Bare-Metal Learning**: Students see a real-world, practical application of bitwise operations (`AND`, `OR`, `SHIFT`) managing physical automated industrial hardware.
